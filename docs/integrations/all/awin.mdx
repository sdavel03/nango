  <Tab title="🚨 API gotchas">
      - Awin calls the credential an "OAuth2 token" in its UI, but it is a static bearer token: there is no authorization flow and it does not expire on its own. Paste it into Nango as an API key.
      - Most reporting endpoints are scoped to one account, e.g. `/advertisers/{advertiserId}/reports/publisher`. The advertiser ID is not the same as your Awin login and is listed under `/accounts`.
      - Affiliate transactions are provisional. The same month pulled twice can legitimately differ as transactions move between `pending`, `confirmed` and `declined`, so treat the pull date as part of what the numbers mean.
      - Rate limits are applied per endpoint group and are not documented in the response headers.

# Overview

To authenticate with Awin, you need:
1. **API Token** - a token that grants Nango permission to read your Awin account's reporting data.

This guide will walk you through generating an API token within Awin.

### Prerequisites:

- You must have an Awin advertiser or publisher account.

#### Step 1: Generating Your API Token
1. Sign in to the [Awin UI](https://ui.awin.com/).
2. Open the user menu in the top right and choose **Account Settings**.
3. Go to the **API credentials** tab.
4. Click **Create a new token**.
5. Copy the token that is shown.

<Tip>Awin calls this an OAuth2 token, but there is no authorization flow — it is a static bearer token you paste in. Copy it now; Awin will not show it again.</Tip>

#### Step 2: Enter credentials in the Connect UI

Once you have your **API Token**:
1. Open the form where you need to authenticate with Awin.
2. Enter your **API Token** in the designated field.
3. Submit the form, and you should be successfully authenticated.

You are now connected to Awin.
